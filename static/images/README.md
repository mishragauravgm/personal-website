# Images Directory 📸

This directory contains folders for organizing your personal pictures that will be used on your website.

## Folder Structure:
- `cats/` - Pictures of your cats and foster cats
- `cooking/` - Your culinary creations and cooking adventures
- `hikes/` - Outdoor adventures and hiking photos

## How to Add Images:
1. Upload your images to the appropriate folder
2. Use descriptive filenames (e.g., `my-cat-mittens.jpg`, `fusion-curry-dish.jpg`, `white-mountains-summit.jpg`)
3. Reference them in your markdown content using relative paths

## Image Guidelines:
- **Formats**: JPG, PNG, or WebP
- **Size**: 800px-1200px wide for good quality
- **File Size**: Keep under 2MB for faster loading
- **Naming**: Use lowercase, hyphen-separated names (no spaces)

## Using Images in Content:
```markdown
![Alt text](/images/folder-name/image-name.jpg)
```

Example:
```markdown
![My adorable cat Mittens](/images/cats/mittens-sleeping.jpg)
```

## Tips:
- Always include descriptive alt text for accessibility
- Consider creating galleries for multiple related images
- Test images on different screen sizes
- Optimize images for web (compress if needed)
